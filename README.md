# reunie25

Website for the reunion of 25 years Scouting Brandevoort (Helmond), Sunday 23 May 2027: https://reunie.scoutingbrandevoort.nl

Static HTML/CSS/JS on GitHub Pages, with Supabase for sign-up and login. Site files live in the root; `_docs/` (management notes, Dutch) and `_supabase/` (database schema) are not published.

Split off from `lastscoutstanding/lastscoutstanding.com` (folder `reunie25/`) with its history on 22 November 2026.
