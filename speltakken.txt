# Speltakken van Scouting Brandevoort
#
# Formaat per regel:   Naam = leeftijd waarop je erbij komt
# De volgorde telt: je zit in een speltak tot je de leeftijd van de volgende hebt.
# De laatste speltak met een leeftijd loopt door tot nu ("heden").
#
# Iedere speltak verschijnt twee keer op het inschrijfformulier:
# bij "Als jeugdlid" (jaren berekend uit het geboortejaar)
# en bij "Als leiding" (jaren zelf invullen).
#
# Een regel zonder "= leeftijd" is een rol zonder speltak, zoals bestuur.
# Die staat alleen bij "Als leiding", met zelf ingevulde jaren.
#
# Speltakken met dezelfde leeftijd lopen naast elkaar (Vuurvogels en Plusscouts horen
# allebei bij de Stam): je zit er tot de leeftijd van de eerstvolgende hogere speltak.
#
# Oude of andere namen komen achter een |, gescheiden door komma's. Op het formulier
# kiest iemand dan bij "Heette toen" de naam van zijn tijd (of typt een andere); op
# het kaartje staat die naam. Zoeken en filteren gaat via de huidige naam.
# Zet de namen die het meest gebruikt zijn vooraan.
#
# Regels die met # beginnen worden overgeslagen.
